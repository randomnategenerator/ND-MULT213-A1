
# Theme

The theme of my website is a **Music Explorer** that allows a user to look up an artist, album, or song, and find out different information about it. I plan to use the [**Spotify**](https://developer.spotify.com/documentation/web-api/reference/get-an-artists-top-tracks) API for the bulk of the content, allowing users to search Spotify's database for information and playback.

> I also plan to implement additional APIs to show content such as news, images, and videos. I am going to wait and see if I have time to implement these features, but I would love to integrate a variety of APIs to create a content-rich website.
> Some potential features I may add to the website include searching and viewing videos, which could utilize the [YouTube API](https://developers.google.com/youtube/data/reference/rest/v3/search/list), and searching for news articles about the search query, which could use the [NewsAPI](https://newsapi.org/). As I develop this webpage further, I will research different APIs, their endpoints, and how I can use them to get a variety of interesting data.

The Spotify API has many endpoints to get information about albums, artists, and tracks. However, there are many additional endpoints that use Spotify features such as playback, search, playlists, and user information. 

> If I have time, I plan to implement features that allow users to create and edit playlists, and play songs that they search using these available endpoints. I will start this project with simple databases searches and then move on to more complicated playback and playlist features.

The user will interact with the page through search and playback functions, with potential features like allowing users to edit content on Spotify and collect their favourite songs. Once I become more familiar with the Spotify API, I will better understand how to implement these features.
